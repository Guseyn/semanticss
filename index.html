Main Concepts

S-Style is a CSS architecture built on the idea that clarity comes from structure—not from endless utility classes. Instead of decorating your HTML with styling tokens, your layout emerges naturally from the relationship of elements.

Core principles:

  • No CSS classes — all styling is semantic and element-driven.

  • Layouts depend entirely on element relationships.

  • Custom elements like <s-row> and <s-column> define structure.

  • Typography is fully automatic with consistent spacing rules.

  • Tables, tooltips, modals, lists, and forms follow unified defaults.

  • Themes are configured through CSS variables — switchable instantly via JS.

  • Mobile and tablet layouts adapt through variables, not class rewrites.

Philosophy

The browser already knows how to render text, flow content, and adapt layouts. Traditional CSS frameworks interfere with this natural flow by layering abstractions: grids, utilities, reset packages, spacing units, breakpoints, and custom components.

S-Style does the opposite.
It accepts the browser for what it is and enhances it in small, powerful ways:

  1. Beautiful typography by default.
  2. Layout primitives that match how humans think — row, column, scrollable.
  3. Readable components without classes.
  4. Automatic responsiveness via tokens, not manual CSS rewrites.
